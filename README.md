# Haus23 Tipprunde

## Project: Remix the Web App @tipprunde/www

This repository holds the rewrite of the public **www** part of the Haus23 Tipprunde app,
the client frontend that players use to follow the rounds, matches, tips and standings.

The rewrite is built on [Remix 3](https://remix.run).

## Getting Started

Install the dependencies with [pnpm](https://pnpm.io):

```sh
pnpm install
```
